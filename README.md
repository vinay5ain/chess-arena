Chess Tournament Web App

Full-Stack Web Application for organizing and managing chess tournaments with player registration, matchmaking, and knockout logic.

🌐 Live Demo
https://chess-arena-l9c4.onrender.com

🚀 Features

Player Management: Register, login, and join tournaments.

Tournament Management: Admin panel for creating and managing matches.

Matchmaking & Knockout Logic: Automatic or manual match scheduling with round tracking.

Real-Time Leaderboard: Displays ongoing scores and rankings dynamically.

Player Profiles: Individual match history and performance stats.

Responsive UI: Works seamlessly on desktop and mobile devices.

🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript

Backend: Node.js, Express.js

Database: MongoDB with Mongoose

Other Tools: VS Code, Postman, Render

💡 Key Concepts & Skills Learned

Full-stack development with Node.js and MongoDB.

Implementation of real-time data handling.

Design and management of relational data structures for tournaments and matches.

Building responsive, user-friendly UI.

Admin and user authentication management.

📋 Installation & Setup

Clone the repository:

git clone <repository-link>


Install dependencies:

cd chess-tournament-web-app
npm install


Configure MongoDB connection:

Replace the MongoDB URI in config.js or .env file.

Start the server:

npm start


Access the app:
Open http://localhost:3000 in your browser.
